This directory contains automatically generated topic segementations
(and possibly subtopic segmentations down the line).

Topic files are named <meeting-ID>.topics.txt, and consist of one record per
line in the following format (blank lines, and lines starting with '#', are
ignored):

  <topic-number><TAB><start-time><UNDERSCORE><end-time><TAB><topic>

For example here, topic 0 runs from 0.4 seconds into the meeting until
26.04 seconds, and covers introductory comments:

  0     0.4_26.04       Introductory comments

Currently records are all stored in-order, which renders topic number
redundant; nevertheless the topic number, and the underscore separating
start and end times, remain for historical reasons.

Historically, the JFerret TopicDisplay plugin has expected these files to be
named <meeting-ID>.lcseg.hyp.label; this is probably the output from one of
Gabriel's (now unknown?) processes.  Sabrina's LCSeg-based process, currently
the source of these files, used to produce topic files named
<meeting-ID>.unk.lcseg.jfer.
